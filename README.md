# Мастер по ремонту (RepairMaster)

Офлайн-справочник по ремонту электроники для Android: бытовая, компьютерная и
промышленная техника плюс общие знания. Каждая тема и каждая проблема снабжена
пошаговой инструкцией: симптом → причины → диагностика → ремонт → инструменты →
техника безопасности.

Репозиторий: <https://github.com/kidjinbruh-del/repair-master-android>

## Как добавить контент

Контент лежит в `app/src/main/assets/content/*.json` — по одному файлу на группу
тем. Файлы читаются в алфавитном порядке, порядок разделов на главном экране
задаётся полем `group` (`technique` — техника, остальное — справочник).

```json
{
  "categories": [{
    "id": "theory", "title": "Теория", "group": "reference", "icon": "science",
    "summary": "Короткое описание раздела",
    "items": [{
      "id": "theory-ohm", "title": "Закон Ома", "summary": "…",
      "images": ["img/ohm_law.webp"],
      "blocks": [
        {"heading": "Формулы", "type": "table",
         "headers": ["Форма", "Формула"], "rows": [["Ток", "I = U / R"]]},
        {"heading": "Шаги", "type": "steps", "items": ["первый шаг", "второй"]}
      ],
      "warnings": [{"level": "danger", "text": "…"}],
      "problems": [{
        "id": "…", "title": "…", "severity": "low", "device": "…", "time": "20 мин",
        "symptoms": ["…"],
        "causes": [{"text": "…", "check": "как проверить"}],
        "diagnostics": [{"title": "…", "detail": "…"}],
        "fix": [{"title": "…", "detail": "…"}],
        "tools": ["…"], "warnings": ["…"], "images": ["img/…webp"]
      }],
      "models": [{
        "name": "…", "brand": "…", "years": "…", "note": "…",
        "specs": [["Параметр", "Значение"]],
        "problems": [ /* тот же формат, что и problems */ ]
      }]
    }]
  }]
}
```

Код менять не нужно: пересоберите APK. Иллюстрации генерируются кодом:

```powershell
python tools\gen_images.py --only ohm_law   # перегенерировать одну картинку
python tools\gen_images.py                  # все сразу
```

## Подбор деталей

Отдельный экран «Подбор деталей»: вводите маркировку, название детали **или модель
устройства** — приложение разбирает запрос, уточняет его по встроенной базе,
показывает параметры и аналоги, затем ищет товары на площадках.

Три слоя работы:

1. **Разбор запроса** (`data/parts/PartQuery.kt`, 194 детали в `assets/db/`, 24
   площадки в ссылках) — работает всегда, без сети. Из строки достаются:
   - **маркировка**: `1N4007`, `L7805CV`, `14D471K`, `7805`, `6205`, `0805`, `SOT-223`;
   - **модель устройства**: `Philips HR1858`, `Keenetic Giga`, `iPhone 12`,
     `Samsung Galaxy A50`, `Bosch MUC2`, `De'Longhi Dedica` — бренд + код;
   - **название детали**: ~70 синонимов до канонического («тачскрин» → Дисплей,
     «помпа» → Насос, «ТЭН» → Нагревательный элемент);
   - **параметры**: `470 мкФ`, `25В`, `0805`, `1.5А`.

   Из этого строится до шести вариантов запроса: «Philips HR1858 Ремень»,
   «Ремень для Philips HR1858», «Philips HR1858», «Ремень» — и они показываются
   чипами «ПОИСКАТЬ ИНАЧЕ». Площадки по-разному относятся к длинным и коротким
   строкам, поэтому если первая не дала ничего, поиск повторяется по следующей.

2. **Живой поиск** — параллельные запросы к источникам, у каждого свои эндпоинты
   и парсеры:
   - **Яндекс Маркет** — Schema.org (`ItemList` из `Product`): название, цена,
     фото, рейтинг, ссылка. Устойчив к редизайну вёрстки.
   - **ChipDip** — разбор строк `product_row`: цены, наличие, фото. Основной
     склад радиодеталей и запасных частей к телефонам.
   - **Wildberries / Ozon** — неофициальные внутренние API. Работают, когда
     сеть и IP не под антиботом; иначе честно показываем статус.
   - **Avito** — только ссылка в браузер, сеть не трогаем вовсе.

   Один источник не может утащить весь поиск: на него повешен жёсткий дедлайн,
   куки прогреваются с кешем, а после трёх подряд блокировок площадка временно
   отключается и пишет об этом в статусе. Ссылки на 24 площадки (Ozon,
   Wildberries, AliExpress, Avito, СберМегаМаркет, DNS, Citilink, М.Видео,
   Эльдорадо, E-katalog, ChipDip, Pleer, Exist, Emex, картинки и datasheet)
   работают всегда, независимо от блокировок.

Измеренная реальность с антибот-защитой площадок (проверено живыми запросами):

| Площадка | Что отвечает |
|---|---|
| Яндекс Маркет | 200, товары и цены получены |
| ChipDip | 200, товары и цены получены |
| Wildberries | 403 на всех версиях эндпоинта из приложения |
| Ozon | 403 / таймаут, защитная заглушка вместо данных |
| AliExpress | та же защита |
| Citilink | 429, JS-защита |
| DNS | 401, антибот |
| Avito | поиск отдаёт только браузеру |

Поэтому в настройках есть честный статус каждого источника и кнопка «Проверить
площадки» — она показывает, что площадка ответила. Неофициальные источники
(WB, Ozon) можно выключить одной кнопкой; остальной справочник от этого не
страдает.

Картинки грузятся лениво: в списке только превью нужного размера и только для
видимых строк, полный размер — по тапу. Кэш двухуровневый (память + диск),
ограничен 96 МБ, есть очистка. Режимы: только Wi-Fi / всегда / не загружать.

Разрешение `INTERNET` используется только на этом экране — весь справочник по
прежнему работает офлайн.

Добавить свою деталь — одна запись в `assets/db/parts.json`, код менять не нужно.
Свой список моделей устройств — `assets/db/device_models.json` (необязательно).


## Сборка

Требуется JDK 17 и Android SDK. Путь к SDK указывается в `local.properties`
(в репозитории не хранится — он привязан к машине):

```properties
sdk.dir=C:/путь/к/Android/Sdk
```

```powershell
# Gradle wrapper сам скачает нужную версию Gradle
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-17"
.\gradlew.bat assembleRelease      # APK: app\build\outputs\apk\release\app-release.apk
.\gradlew.bat assembleDebug        # отладочная сборка (applicationId + .debug)
```

Установка на устройство:

```powershell
adb install -r app\build\outputs\apk\release\app-release.apk
```

## Графика

Иллюстрации генерируются кодом (SVG → WebP, 2x) — `tools/`:

```powershell
python tools\gen_images.py                     # все картинки
python tools\gen_images.py --only wire_awg     # одна картинка
```

- `tools\assets.py` — определения всех иллюстраций
- `tools\draw.py` — примитивы (резистор, конденсатор, диод, транзистор,
  мультиметр, паяльник, панели, таблицы)
- `tools\gen_images.py` — рендер через Chromium (Playwright) + Pillow → WebP

Результат: `app\src\main\assets\img\*.webp`.

## Тесты

Разбор запроса и парсеры ответов площадок — чистый Kotlin и `org.json`, поэтому
проверяются обычными юнит-тестами на кусках живых страниц:

```powershell
.\gradlew.bat testDebugUnitTest     # 26 тестов: QueryAnalyzerTest + PartsParserTest
```

Если площадка поменяет разметку, тест сломается сразу — это и есть защита.
